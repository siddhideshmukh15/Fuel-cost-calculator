# Fuel Cost Calculator

A simple **Fuel Cost Calculator** built using Python. This beginner-friendly project calculates the estimated fuel cost for a journey based on distance, vehicle mileage, and fuel price.

## Features

- Accepts journey distance
- Accepts vehicle mileage
- Accepts fuel price
- Calculates fuel required
- Calculates total fuel cost
- Displays the result clearly

## Technologies Used

- Python
- User input
- Variables
- Arithmetic operators
- `float()`

## Concepts Learned

- Taking user input
- Type conversion
- Variables
- Arithmetic calculations
- Division and multiplication
- Basic problem-solving
